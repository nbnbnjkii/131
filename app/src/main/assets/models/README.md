# GLB-модели

Сюда кладутся GLB-модели, которые загружает нативный рендерер (`cpp/Renderer.cpp`).
Без этих файлов приложение покажет экран ошибки загрузки — APK при этом собирается.

Ожидаемые имена файлов:

| Файл | Назначение |
| --- | --- |
| `abandoned_city_street_for_games.glb` | Город (уровень, коллизии, спавн) — обязательный |
| `uaz_469_1973_classic.glb` | УАЗ на парковке |
| `chasing_m2_rc_underwater_drone_remote.glb` | Пульт FPV-дрона (viewmodel) |
| `fpv_drone.glb` | FPV-дрон |
| `player.glb` | Модель игрока (вид от 3-го лица) |

После добавления файлов просто пересоберите APK — модели упакуются в `assets/models/`.
