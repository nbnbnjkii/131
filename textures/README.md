# Текстуры города — этап 1

В APK включены четыре процедурные бесшовные **RGB PNG 512×512**:

- `asphalt.png` — тёмный зернистый асфальт, трещины;
- `concrete.png` — пятнистый бетон;
- `brick.png` — кирпич с раствором;
- `rust.png` — металл с неоднородной ржавчиной.

Изображения созданы скриптом проекта, не скачаны со сторонних сайтов. Пересоздать из корня репозитория:

```sh
python3 tools/generate_android_textures.py
```

Любое изображение можно заменить PNG с тем же именем. Загрузчик нормализует размеры до 512×512; лучше сразу использовать 512×512 без рамок, надписей и освещения, запечённого с одного направления. Ограничения: до 32 МиБ сжатых данных и 4096×4096 декодированных пикселей. Эти ограничения защищают загрузку от чрезмерных выделений памяти.

Отсутствующий/повреждённый файл заменяется спокойной клетчатой текстурой цвета материала; причина выводится в logcat с тегом `Ekron`. Это не должно прерывать запуск из-за отсутствия PNG. Если GPU не может создать массив текстур, рендерер продолжает работу с цветными материалами.

Это **albedo/base color**, не полный набор PBR. Normal, roughness, metallic и AO-карты пока отсутствуют. Текущая модель освещения — Lambert + рассеянный свет неба, без теней и отражений.
