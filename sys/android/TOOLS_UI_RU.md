# v0.12 — контекстные инструменты

## Состояния и UI
`HandTool` в ToolState.kt: HAND_EMPTY, SPAWN_GUN, GRAVITY_GUN, DELETE_TOOL.
`ToolState` — независимая от Android логика, покрытая unit-тестами. `renderTools()` — единая точка обновления видимости. Используется GONE: скрытые кнопки не занимают места и не перехватывают касания.

- Пустые руки: только «Рюкзак» для инструментов снизу справа. Джойстик, пауза, прыжок и позы — отдельное постоянное управление, они остаются.
- Меню рюкзака: пустые руки, спавн-пушка, грави-пушка, удаление. Выбор сбрасывает контекст захвата; отмена меню ничего не меняет.
- Спавн-пушка: «Блоки» (каталог), «Поставить блок» (куб), «Влево» и «Вправо». Предпросмотр только с этим инструментом.
- Грави-пушка: «Захват». Только после подтверждения реального захвата native-миром — «Отпустить» и «Вращать». Неудачный захват не включает фиктивное состояние удержания. Неудачное отпускание в занятую позицию сохраняет предмет в захвате.
- Удаление: единственная красная кнопка «Удалить», удаляет только пользовательские объекты.

Контекстные кнопки расположены снизу по центру, отдельно от джойстика и кнопок позы, рюкзак — справа. Размеры действий не менее 72x64 dp, рюкзак 64x64 dp (то есть не менее запрошенных 60x60 физических пикселей). Иконки рисуются Canvas, сеть не используется.

## Native-связь и границы реализации
Native дополнительно проверяет текущий инструмент перед действиями; скрыть кнопку недостаточно для разрешения действия. UI получает инструмент и факт захвата через расширенный nativeStatus. Выбор инструмента сохраняется при пересоздании EGL; захват отменяется безопасно.

Добавлено базовое взаимодействие грави-пушки **с пользовательскими постройками**, не с городом и не с УАЗом. Захват — по лучу взгляда до 8 м, с проверкой перекрытия геометрией города. Предмет плавно приближается к точке перед игроком и вращается шагами 90°. При смене инструмента/уничтожении рендерера возвращается исходная постройка, предмет не теряется. Отпускание размещает предмет на плоскости существующих XZ-построек при успешной проверке размещения. Это не полноценная динамика rigid-body: баллистического броска нет; произвольная высота предмета не записывается в текущий формат сохранений. Кнопка поэтому называется «Отпустить», а не «Бросить». При удержании предмет исключается из BVH построек; тяжёлые городские BVH не пересчитываются.

Проверки: ToolStateTest — все режимы, сброс захвата, подтверждение из мира; tool_interaction_test — выбор, захват, вращение, отмена без потери объекта, преграда перед объектом и отпускание. Сборка Android и остальные native-тесты — CI. Визуальная компоновка и удобство на физическом телефоне пока не проверены.
