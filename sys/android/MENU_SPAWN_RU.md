# v0.40 — спавн из каталога

Постоянная кнопка кубика «Спавн» доступна с пустыми руками и грави-пушкой (скрыта в сиденье). Каталог имеет вкладки Строительство, Мебель, Оружие, Дроны. Первые две содержат существующие предметы; УАЗ сохранён в Строительстве. Оружие и Дроны явно пусты — новых сущностей не добавлено.

Выбор посылает одну атомарную native-команду 300+type: запоминает прежний инструмент, включает временный SPAWN_GUN и задаёт предмет. Зелёный предпросмотр и повороты сохранены. Только успешный commitPreview ставит объект и возвращает грави-пушку/пустые руки. Отказ размещения оставляет предпросмотр активным. Выбор другого предмета внутри предпросмотра не затирает первоначальный инструмент возврата. Выбор в колесе позволяет выйти из предпросмотра без установки. Native enum SPAWN_GUN сохранён для совместимости, но не представлен как отдельный экипируемый инструмент.

В колесе и accessibility-списке теперь два инструмента: грави-пушка сверху, пустые руки снизу. Выбор каталога при захваченном объекте использует прежнюю семантику смены инструмента (отмена захвата). Кнопка установки ждёт native-подтверждения включения предпросмотра, чтобы быстрый клик не обогнал синхронизацию UI.

ToolWheelSelectionTest проверяет два сектора и разбиение каталога без потери существующих предметов. CI собирает APK и запускает JVM/native tests. Реальный телефон/эмулятор не использовался: вручную проверить все вкладки, успешную/неуспешную установку, возврат обоих инструментов, повторный выбор и отмену.
