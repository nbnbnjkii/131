# ЭКРОН — нативная Android-песочница

Основной Android-проект для этих изменений: **`sys/android`**. Дубликаты в `engine/android` и `engine/sys/android` не обновлялись.

Приложение использует существующий GameActivity и библиотеку `librealms.so`. Демонстрационный рендерер с картинкой робота заменён кварталом на **C++ / OpenGL ES 3**. WebView, сайта, JavaScript, npm и подключения к серверу в APK нет. Настольный Pascal-код пока не объединён с Android-рендерером.

## Свободная ходьба и спавн с фото (0.7)

Убраны невидимые заграждения из сетки покрытия пола. Теперь город блокируют тонкие срезы фасадных стен, а не все участки без плоского треугольника земли. Настоящие дверные проёмы сохраняются; декор и машина не блокируют проход. Точный старт включён в конфиге: **X=−3,4; Y=1,7; Z=32,7**.

Причина, новый алгоритм, ограничения и тест пешего маршрута на модели: **[WALKING_FIX_RU.md](WALKING_FIX_RU.md)**. Этот раздел заменяет старые описания сеточных коллизий ниже.

## Отладка и загрузка (0.6)

Добавлены экран загрузки до первого показанного кадра, координаты X/Y/Z с копированием в буфер, noclip с кнопками высоты, аварийное возвращение «На дорогу» и точный спавн через `assets/config/spawn.json`. При выходе из полёта проверяются коллизии и принадлежность основной доступной области; посадка внутри забора переносится на открытое место. Машина из 0.5 остаётся в мире; начиная с 0.7 её коллизия отключена по новой политике декора.

Управление, конфиг и ограничения одноуровневой ходьбы: **[DEBUG_RU.md](DEBUG_RU.md)**.

## Текущий уровень (0.5+)

По умолчанию загружается пользовательский `abandoned_city_street_for_games.glb` через tinygltf, с авторскими UV и встроенными PNG/JPEG. Кубический квартал оставлен только запасным вариантом при ошибке загрузки. Для модели создаются сеточные коллизии и выбирается свободная стартовая точка. Сохранения этого уровня — `city-glb-v1.txt`.

Исправлен спавн: выбирается основная связная область с запасом до препятствий, а не свободный карман за забором. Добавлена отдельная GLB-модель разбитого автомобиля с собственным масштабом и невысоким коллайдером.

Код, внешние PNG, ограничения коллизий и важное замечание о лицензии модели: **[GLTF_CITY_RU.md](GLTF_CITY_RU.md)**.

## Что добавлено в нативный код (базовая песочница)

- Квартал из восьми домов, часть повреждена; входы с настоящими проёмами, простая обстановка, завалы, машины.
- Вид от первого лица. Касание и перетаскивание слева — ходьба, справа — поворот камеры. Два пальца поддерживаются одновременно.
- Коллизии со стенами, мебелью и своими постройками.
- Русские Android-кнопки строительства поверх нативной поверхности.
- «Строить» включает предпросмотр; кнопка с названием переключает предметы, «Повернуть» меняет ориентацию на 90°, «Поставить» размещает предмет.
- Каталог: стена, пол, окно, дверь, стол, стул, шкаф, диван.
- Предпросмотр зелёный при допустимом размещении, красный при пересечении или выходе за границы. «Готово» отменяет предпросмотр.
- «Убрать своё» удаляет ближайший свой объект по горизонтальному направлению взгляда в пределах 9 м.
- До 500 объектов. Автосохранение после изменения в `files/sandbox-v1.txt`, запись через временный файл и rename. Загрузка при старте. Сохранения браузерного прототипа сюда не переносятся.
- При потере фокуса движение сбрасывается, игровой цикл перестаёт активно рисовать в фоне.
- Добавлены отсутствовавшие в Git AndroidManifest и тема приложения; горизонтальный полноэкранный режим.
- Заданий, целей и сюжетных маркеров нет.

## Текстуры и освещение (0.3)

- `TextureLoader.h/.cpp`: stb_image (vendored `third_party/stb_image.h`, встроенная лицензия MIT/public domain), чтение PNG через AAssetManager, запасные текстуры при ошибке.
- `assets/textures/`: четыре процедурных бесшовных 512×512 PNG. Генератор без внешних зависимостей: `tools/generate_android_textures.py`.
- `MeshGeometry.h`: нормали каждой грани и UV в мировых метрах — один повтор на 2 метра, без растягивания на всю стену.
- Массив из пяти слоёв GL_TEXTURE_2D_ARRAY (четыре материала и белый слой для мебели/предпросмотра), sRGB-декодирование, GL_REPEAT, mipmaps и трилинейная фильтрация. Около 6,7 МиБ для массива с mipmaps.
- В `Renderer.cpp` встроены полные GLES 3 шейдеры: направленный свет, прохладное рассеянное освещение, экспоненциальный туман и процедурный градиент неба. Свет считается в линейном RGB, итог выводится с gamma-коррекцией.
- Небо рисуется полноэкранным треугольником без текстурного skybox и не перекрывает геометрию по глубине.
- Материалы назначены дороге, бетону, обломкам и кузовам машин. Формат сохранения построек не менялся.

Это первый этап, **не полноценный PBR**: пока нет normal/roughness/metallic/AO, теней или отражений. Детальная геометрия и новый HUD из ТЗ ещё не реализованы.

## Сборка APK

Нужны JDK 17, Android SDK 34 / Build Tools 34.0.0, NDK 26.1.10909125, CMake 3.22.1, доступ к Google Maven и Gradle.

```sh
cd sys/android
# При необходимости укажите путь sdk.dir в local.properties (не коммитить).
./gradlew :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Debug-пакет подписывается отладочным ключом. Для обновления уже установленного APK нужен тот же ключ подписи; удаление приложения очищает постройки.

В `.github/workflows/android-sandbox.yml` добавлена сборка на push/PR и ручной запуск. При успешном выполнении артефакт `ekron-native-sandbox-debug` содержит APK. Наличие workflow не означает, что сборка уже прошла.

## Проверки и ограничения

Проверка логики без Android SDK:

```sh
# Из корня репозитория
g++ -std=c++17 -Wall -Wextra -Werror -pedantic tests/native/sandbox_world_test.cpp -o /tmp/ekron-world-test
/tmp/ekron-world-test
```

Проверяются размещение, запрет пересечений, поворот габаритов, удаление, сохранение/загрузка, отклонение повреждённых сохранений, вход в дом и столкновение со стеной.

Проверки текстур и UV (также выполняются в CI):

```sh
g++ -std=c++17 -Wall -Wextra -Werror -pedantic tests/native/texture_mesh_test.cpp -o /tmp/ekron-texture-test
/tmp/ekron-texture-test
# При установленном glslangValidator:
python3 tools/validate_android_shaders.py
```

Проверяется декодирование всех PNG через stb_image, размеры 512×512, совпадение краёв для tiling, нормали, слои материалов и UV. CI дополнительно проверяет компиляцию/линковку GLSL ES шейдеров. Это не заменяет тестирование рендера на реальном GPU.

В среде разработки нет Java/SDK/NDK: тесты логики выполнены, но компиляция Android JNI/GL-кода, установка APK, визуальный результат и мультитач на устройстве локально не проверены.

Графика — цветная низкополигональная заготовка, не детализация концепта. Один ограниченный квартал; нет стриминга мира, боя, прыжка, разрушаемости или мультиплеера. Строительство только на земле, без этажей и соединения элементов; коллизии двумерные. Окно и дверь пока декоративные, не открываются. Удаление использует горизонтальный луч, не учитывает высоту прицела и перекрытие стеной. Уведомления об ошибке сохранения пока только в logcat. Перед выпуском нужны доработка выбора объектов, оптимизация мешей, реальные модели/текстуры и проверка на телефоне.
