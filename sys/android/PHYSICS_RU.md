# v0.8: геометрия и локальная заставка

Игровая ходьба использует капсулу (радиус 25 см, высота 180 см) и BVH треугольников GLB, а не старые двумерные полосы фасадов. Последние сохранены только для поиска дороги/парковки и совместимости тестов. Прозрачные материалы не создают препятствий; бетонные треугольники остаются физическими. Пустые проёмы не закрываются автоматически. Узкий проём может требовать прыжка и приседания (высота 100 см); если сама GLB содержит сплошную непрозрачную грань, она остаётся препятствием.

Гравитация рассчитывается с шагом 1/120 с, с ограничением шага кадра; крыши, пол, ямы и наклоны берутся из модели. Сглаживается только высота камеры. Отключение полёта сохраняет текущую позицию и обнуляет вертикальную скорость, без поиска дороги. Явная кнопка «На дорогу» запускает поиск в рабочем потоке. Начальная позиция из assets/config/spawn.json: -3.4 / 1.7 / 32.7. Частный files/spawn.json по-прежнему может переопределить конфиг.

Автомобиль ориентирован вертикально; высота основания определяется поверхностью под его центром и четырьмя точками опоры. На неровной поверхности жёсткий горизонтальный автомобиль может иметь зазор под отдельным колесом.

assets/intro.mp4 — локальная копия gemini_generated_video_4c8974e7.mp4 из корня репозитория. MediaPlayer читает asset через файловый дескриптор, интернет не используется; mp4 хранится без сжатия APK. После завершения видео показывается индикатор ещё минимум три секунды. Дополнительно ожидается первый кадр мира. До этого ввод и физика заблокированы на native-стороне. При ошибке декодера применяется та же трёхсекундная задержка, чтобы не зависнуть навсегда. При паузе Activity проигрывание и управление приостанавливаются.

Поиск дороги и запись сохранений выполняются асинхронно. Переключение строительства не пересчитывает город. BVH города строится однократно при загрузке; маленький BVH пользовательских объектов обновляется только при изменении постройки. Создание GL-контекста/загрузка GPU остаются на native render thread под заставкой.

Проверки: tests/native/player_physics_test.cpp — падение без телепорта, приземление на крышу, сход с крыши, прыжок, дно ямы, стабильный склон, бетонная рама и пустой проём. Старые native-тесты также сохраняются. Реальное воспроизведение/производительность и проходимость всех окон на Android-устройстве требуют ручной проверки; эмулятор в среде разработки отсутствует.
