# Отладка мира: загрузка, координаты, полёт (0.6)

## Экран загрузки

Android HUD показывает «ЭКРОН / ЗАГРУЗКА МИРА», вращающийся индикатор и текущий этап: графика, текстуры, город, машина, коллизии, первый кадр. Это реальные этапы нативного потока, не выдуманный процент. Оверлей скрывается только после успешного `eglSwapBuffers` первого кадра. При ошибке инициализации/вывода кадра показывается сообщение вместо бесконечного чёрного экрана. До создания Activity окно имеет тёмно-синий фон.

UI работает на Android main thread, загрузка GLB — на нативном потоке GameActivity. Передача этапов — через atomic, координат — через защищённый mutex снимок. UI не читает изменяемый World напрямую. Обновление примерно 10 раз в секунду; polling останавливается в фоне.

## Координаты и управление

- Под заголовком постоянно отображаются **X, Y, Z**. Y — высота камеры, не ног; обычная ходьба сейчас на Y=1,7 м.
- Касание строки координат копирует JSON для `spawn.json` в буфер обмена, с точностью до четырёх знаков. Отображение на HUD округлено до одного знака.
- «✈ Полёт» включает noclip: свободное движение сквозь город, машину и постройки. Движение слева учитывает направление взгляда, включая наклон камеры.
- В полёте появляются удерживаемые кнопки **↑ Вверх / ↓ Вниз**. Кнопки прекращают движение при отпускании, отмене касания и потере фокуса. Самопроизвольного падения нет.
- При выключении полёта Y возвращается к 1,7. Если текущая точка находится в стене/машине/заборе или в отдельном замкнутом участке, выбирается ближайшая свободная точка основной связной области.
- «На дорогу» — аварийный возврат к безопасному старту перед городом. Если всё подходящее пространство застроено, вместо удаления построек включается/остаётся полёт с предупреждением.
- Полёт ограничен отладочными пределами X/Z ±512 м, Y от −100 до 200 м. Скорость порядка 8 м/с.

Это режим отладки, не полноценная физика: прежняя ходьба остаётся одноуровневой, без гравитационного контроллера, лестниц и этажей. При выключении полёта игрок переносится на опорный уровень, а не физически падает на крышу под ним.

## Точная точка спавна

Файл в репозитории:

```
sys/android/app/src/main/assets/config/spawn.json
```

Пример для ходьбы:

```json
{
  "enabled": true,
  "position": {"x": 0.614487, "y": 1.7, "z": 31.625},
  "yawDegrees": 0,
  "startFlying": false
}
```

1. Найдите место в полёте, посмотрите координаты или нажмите на них для копирования JSON.
2. Впишите координаты в файл, поставьте `enabled: true`, пересоберите APK.
3. Закройте процесс игры и запустите заново. При пересоздании только EGL-поверхности текущая позиция и режим сохраняются в памяти, конфиг не перезагружается.

`enabled: false` (по умолчанию) выбирает безопасный автоматический спавн. Допустимая ручная точка ходьбы сохраняется **точно**, без округления к навигационной сетке. Небезопасная точка переносится в основную открытую область, с предупреждением на экране. Проверка выполняется после загрузки города, машины и сохранённых построек.

Для точного высокого/подземного спавна используйте `startFlying: true`. Если Y отличается от 1,7 более чем на 0,01, полёт включается автоматически: существующий одноуровневый контроллер не может корректно ходить по произвольной высоте. В явно заданном отладочном полёте XYZ соблюдаются без проверки 2.5D-стен — это сознательная возможность исследовать любую часть модели. Автоматический и ручной **пеший** спавн за замкнутым забором не допускаются алгоритмом связности. Невалидный JSON/нечисловые или чрезмерные координаты дают предупреждение в logcat и автоматический старт.

### Без пересборки (debug APK, через ADB)

Приватный файл `files/spawn.json` имеет приоритет над assets:

```sh
adb shell am force-stop com.example.realms
adb shell "run-as com.example.realms sh -c 'cat > files/spawn.json'" < spawn.json
# Откройте игру с телефона.
```

Удаление переопределения:

```sh
adb shell run-as com.example.realms rm files/spawn.json
```

`run-as` доступен для отладочной сборки. Файл ограничен 64 КиБ. Наличие конфига не изменяет сохранённые постройки.

## Машина и тесты

Разбитая машина `models/crushed_sports_car.glb` из 0.5 остаётся в сцене: 4,3 м длина, около 1,43 м высота, AABB высотой 1,2 м и реальным горизонтальным габаритом. В пешем режиме её коллизия действует, в полёте игнорируется вместе с остальными.

`tests/native/debug_player_test.cpp` проверяет конфиг, точность безопасного X/Z, свободное движение/высоту без падения, возврат из стены и замкнутого забора, отказ от посадки при полностью заблокированной карте. Существующие тесты квартала и парковки продолжают проверять машину и доступный проход. Android HUD, задержка первого кадра и мультитач требуют проверки на физическом устройстве.
